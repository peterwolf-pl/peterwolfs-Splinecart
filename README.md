# Splinecart

Use `/splinecart banking on` to make newly linked curved spline tracks bank into
their turns. `/splinecart banking off` disables the build mode and
`/splinecart banking toggle` switches it quickly.

Use `/splinecart smoothing on|off|toggle` to control whether newly placed and connected
track ties use smooth curve tangents or rigid block orientation. During building, you can
also Sneak + Right-Click in the air with a Track or Track Ties item to toggle your default smoothing mode,
or Sneak + Right-Click any track tie to toggle smoothing on that specific tie. The HUD indicates
the targeted tie's smoothing status in real time.
